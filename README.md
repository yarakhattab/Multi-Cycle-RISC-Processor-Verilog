# 🔧Multi-Cycle RISC Processor in Verilog

## 📘 Project Summary
This repository showcases our work for Project #2 in the Computer Architecture course at Birzeit University. The goal was to design, implement, and simulate a **multi-cycle RISC processor** using Verilog, capable of executing a subset of a custom ISA (Instruction Set Architecture).

## ⚙️ Project Highlights
- 🧠 **Multi-Cycle Execution Model**
- 🧮 **16-bit Data and Instruction Memory**
- 🧾 **8 General-Purpose Registers (R0–R7)**
- 📚 **Instruction Types**: R-Type, I-Type, J-Type, S-Type
- 📦 **Byte-Addressable Memory** using Little Endian format
- 🔍 **Branch Logic and ALU Condition Flags**
- 🧩 **Control Unit** implemented using truth tables and Boolean equations
- 🛤 **Datapath & Control Path** fully designed with diagrams
- 🧪 **Testbench** for functional verification and simulation


## 🚀 Getting Started
To try out the project:

1. Clone the repository
2. Open it in a Verilog simulation environment (e.g., ModelSim, Icarus Verilog).
3. Load the source files.
4. Run the test programs and observe the simulation outputs.
5. Use waveform viewers to validate the processor’s behavior.
